# Skyward · Flight Booking

A React + Vite static flight-booking experience reconstructed from the exported Claude conversation.

## Features
- Flight search with origin, destination, dates and passengers
- Flight cards with timings, duration, price and airline
- Filtering and sorting
- Fare comparison
- Interactive seat selection
- Passenger form and booking summary
- Booking confirmation with split-flap animation
- LocalStorage booking history
- Multi-city search
